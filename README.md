# OpenCritique

OpenCritique is a local-first fitness and workout progression tracking application built with React, TypeScript, and Tailwind CSS. It features a 12-tier gemstone ranking system, interactive habit tracking, structured workout execution with live set validation, and an AI training coach.

## Features

- **12 Gemstone Rank Progression**: Beginner (Bronze), Novice (Silver), Apprentice (Jade), Intermediate (Garnet), Skilled (Topaz), Advanced (Citrine), Elite (Sapphire), Expert (Emerald), Master (Ruby), Grandmaster (Amethyst), Legend (Opal), and Apex (Diamond).
- **Workout Tracking & Stepper**: Complete workouts with exercise progression, set logs, target vs. actual weight and repetitions, and real-time set validation.
- **XP Policy Engine**: Difficulty-based XP system awarding experience points for workouts (Leg Day, Upper Body, Full Body, Conditioning, Calisthenics, Sport Performance) and daily habits (Easy, Moderate, Hard, Very Hard).
- **Daily Habits**: Track hydration, mobility, stretching, and recovery habits with live XP accumulation.
- **AI Coach**: Generate customizable 7-day training cycles based on primary goal, experience level, weekly frequency, and equipment access.
- **Milestones & Leaderboard**: Track achievements (First Workout, Program Started, Habit Builder, XP Milestones) and tier standings.
- **Local-First Architecture**: User data stays private and stored locally on device with full backup export and reset controls.
